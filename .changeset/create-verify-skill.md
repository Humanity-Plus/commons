New `create-verify-skill` skill: generates — or refreshes — a repo-local `verify-<app>` skill that drives the real app the way a user does (launch, doctor, personas, drive, evidence, cleanup) plus a feature map with one file per user-facing feature, its source **Paths** and the seeded **Personas** it needs, proven by an observable end state. The generator interviews the repo, writes the skill into the host's project skill directory, and drives one feature end to end before handing over; refresh mode runs source readers per feature and one live pass and leaves only proven corrections in the working tree (a PR when asked). Both modes run on your own checkout against a local or disposable instance. The toolkit consumes the skill by shape: `review-pr` runs experiment claims and the blast-radius probe through its recipes on owned checkouts, and `resolve-review` drives the features a review touched after its fixes land, with the outcome in the resolution ledger. The method adapts the `create-verification-skill` and `maintain-verification-skill` skills in Lauren Tan's (poteto) MIT-licensed pstack, credited in the toolkit README.
