Field round from a five-PR queue run. `review-pr`: a repeated mechanical substitution (the same literal, rename, or import swap in every hunk) takes the light tier however many files it touches, and the light-tier text now defers to the ladder row instead of restating it; when the conflict probe hits most of a PR's files and base replaced what the PR edits, the review asks whether the PR is superseded — goal met on base by reading and measurement — before planning any merge. The `intent` lens compares equivalence and duplication claims (keys, resolved values, exports) instead of accepting them. `recap.ts` emits a one-line classification-only block when no mapped primitive was touched, instead of an empty diagram and table. `reset-workspace.sh` leaves `review-report/verify/` in place when it archives stale findings — evidence dirs are keyed by phase and SHA, and moving them dangled every link the findings recorded. A running verify instance and the review scripts no longer collide: the generator now mandates runtime state (pids, port, head, log, registered clients) in the git dir — `$(git rev-parse --git-dir)/verify/`, shared registrations one level up in the common dir — so `review-report/verify/` holds evidence only; `check-clean.sh` refuses while those pids are alive and fails loudly, leaving the original where it names, instead of nesting `review-report/review-report` when a launch recreated the directory mid-check; a contract test pins the pid-file path across generator and script. Existing generated skills pick the layout up on their next refresh. `create-verify-skill`: identifiers a generated Launch derives from the checkout path are sanitized to the target's charset, Doctor prints them, and refresh mode re-reads Launch, Doctor, and Cleanup against the generator's contract so existing skills pick the rule up. Review-fix on this round added: a superseded verdict is always `comment`, never `approve`; the review-pr README defers to the ladder row and a contract test keeps the light-tier predicate stated once; the light generalist owes a substituted token the hidden-reader grep that blast-radius would have done at a higher tier.
