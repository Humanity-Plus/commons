Redesign the `review-pr` HTML report and tighten the `blast-radius` and `primitives` lenses around plain-language review decisions.

- **Blast radius focuses on unintended collateral impact, not runtime lectures.** The `blast-radius` lens now reports an explicit collateral-impact rating (`contained` / `side-effects` / `breaking`) and plain-language `sideEffects`, keeping `cleared` items to one sentence and making `safetyFact` optional. In `report.html`, unintended effects lead the card while checked-and-unaffected areas and non-contradicted verification probes collapse by default; contradicted assumptions still surface loudly.
- **System change explains how the system changes and checks for primitive duplication.** The `primitives` lens now emits a plain-language `summary`, an explicit `duplicationCheck` (`clean` / `duplicated`), a `mapped` flag on newly added primitives, and separate `invariantsViolated` vs. `invariantsTouched`. `render.ts` and `recap.ts` no longer flag newly mapped primitives as unmapped warnings, never report `Composes` when `added` is non-empty, and reserve warning styling for violated invariants.
- **Cleaner report hierarchy and renderer bugfixes.** A compact inline overview bar (severity pills + section jump links) replaces the bulky donut/section/heatmap cards so Summary, System change, and Blast radius sit above the fold. Empty sections are omitted, `Test gaps` uses readable category names with the ZOMBIES matrix collapsed underneath, `Lenses` moves into the collapsed `Scope & limitations` audit trail, `verdict.summary` supports in-page `#f-...` anchor links, `Preflight` hides empty confidence pills, and `Files reviewed` handles string file lists, `scope` descriptions, and object `skipped` entries without rendering empty rows or `[object Object]`.
- **Two-altitude writing rule.** `finding-style.md` and `SKILL.md` instruct lenses and synthesis to keep overview cards in plain English at the behavior/architecture level while keeping code quotes and mechanical proofs inside findings, and to keep nitpicks and raw internal labels out of the `Classes` card.
